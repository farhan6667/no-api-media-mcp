# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the code, and never post anyone's account details, cookies or screenshots of their private chats in issues.

Report problems to the maintainers through a private GitHub security advisory, by contacting the repository owner on GitHub, or by email at nexaforge.services@gmail.com. Reports are handled privately.
